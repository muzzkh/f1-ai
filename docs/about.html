About
the project

F1 AI turns open Formula 1 timing data into race analysis you can look at, gives AI assistants the same data through an MCP server, and reads telemetry off onboard video. This website is a snapshot; the full project works for any session since 2023.

View the sourceLatest race

Four parts

All built on one data layer and one set of analysis functions, so a number here, in the dashboard and in an AI answer is the same number.

01

Analysis

Clean-lap pace, a fuel-corrected tyre model, measured pit loss, strategy ranking, and laps aligned by GPS so two drivers can be compared point for point.

02

Dashboard

A local app for exploring any session: race, pace and tyres, telemetry, video lab, championship.

03

MCP server

Tools an AI assistant such as Claude can call to answer questions from real timing data instead of guessing.

04

Video to telemetry

Reads the on-screen cluster of an onboard video into a telemetry file, with a renderer that makes test footage to measure accuracy against.

MCP tools

What an assistant can ask for once the server is connected.

Run it

Python 3.10 or newer. The first session you open is downloaded and cached; after that it loads from disk.


    

  


  

    

      
What is real
Better graphics should not overstate what the data can support.

      

        
Real
Circuit shape, elevation, corner numbers, the pit lane path, every lap time, tyre stint, position and overtake, and where each car was on track.

        
Approximate
Car telemetry arrives about four times a second. Sector-level gaps match official timing to a few hundredths; single-corner numbers and racing lines are indicative. Circuit length is measured along a driven line, about 2% short of the official figure.

        
Stylised or modelled
Track width and kerbs are drawn, not measured. The strategy model assumes linear tyre wear, clear air and no safety cars. The video reader is verified only on footage this project renders.
